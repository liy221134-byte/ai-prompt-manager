## 三、schema（zod 骨架）

```ts
// 这份 schema 是唯一正本：入口校验、测试、文档都引用它，不各写一份
import { z } from "zod";

export const 契约名 = z.object({
  字段一: z.string().min(1),
  字段二: z.number().int().positive(),
  // 取值固定时用 z.enum([...])；拿不准的可选字段用 .optional()
});
```

## 四、入口校验（写在哪、失败怎么处理）

```ts
// 在入口处校验，失败立即返回结构化错误，不吞掉、不降级继续
const parsed = 契约名.safeParse(input);
if (!parsed.success) {
  return { ok: false, error: parsed.error.issues };
}
// 只有 parsed.success 才往下走；校验不过的数据不进任何写操作（落库、发请求、改状态）
```
