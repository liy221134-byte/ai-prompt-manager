# 安全检查

> 用途：上线前和接手时各过一遍，防止把密钥、权限和数据暴露出去。
> 项目：`{{项目名称}}`

## 一、密钥与配置

- [ ] 密钥只在服务端使用，命名不带 `NEXT_PUBLIC_` 前缀
- [ ] 密钥不在版本库里，示例文件里只有占位符
- [ ] 预览环境拿不到生产密钥
- [ ] 怀疑泄露过的密钥已经轮换过

## 二、访问控制

| 资源 | 谁能访问 | 靠什么限制 | 越权时会怎样 |
| --- | --- | --- | --- |
|  |  |  |  |

- [ ] 每条数据都能回答「别人拿到它的标识，能不能读到」这个问题
- [ ] 服务端接口逐个确认过权限，不只依赖界面隐藏

## 三、输入与输出

- [ ] 外部输入在进入系统时校验（类型、长度、枚举）
- [ ] 不把用户输入直接拼进 SQL 或命令行
- [ ] 展示用户内容时做转义，不直接当 HTML 渲染
- [ ] 上传文件校验类型、大小和文件名

## 四、日志与隐私

- [ ] 日志里没有密钥、口令和完整敏感内容
- [ ] 明确哪些内容会发给第三方服务，且只在你确认后才发
- [ ] 删除数据有明确入口和回收路径

## 五、维护约定

- 引入新的外部服务或新的数据类别时，回来补这一页。
- 每次安全事件（哪怕只是差点出事）都记一条到「四」下面。
