# 用户故事（3C + INVEST）

> 用途：把一个功能拆成「能独立开发、能单独验收」的用户故事，每条都带验收条件。
> 项目：`{{项目名称}}`
>
> **怎么用**：一次拆一个功能；故事之间互相独立，先做哪条都行；每条控制在一个迭代内做完；
> 用新用户能读懂的话写；有设计稿就贴链接。
> **谁把关**：验收条件由你拍板，AI 起草。

## 五、自查（INVEST）

- [ ] **独立**：不依赖别的故事也能开发
- [ ] **可协商**：讲的是意图，不是实现细节
- [ ] **有价值**：说清了谁得到什么
- [ ] **可估算**：范围清楚，能估个大概
- [ ] **够小**：一个迭代内能做完
- [ ] **可测**：每条验收条件都能点一遍判通过或失败
