# OKR：目标与关键结果

## 核心结论

用一个鼓舞人心的目标 O，加 2–5 个可量化的关键结果 KR，对齐团队一个周期的努力方向。
KR 必须能衡量进度，是「结果」不是「任务清单」。

## 使用条件

- 季度 / 双月的目标对齐。
- 需要跨角色拉齐优先级时。

## 不适用场景

- 个人待办管理（用艾森豪威尔矩阵即可）。
- 目标极不稳定的一周冲刺——OKR 按周期走，太短反而增加负担。

## 执行方法

1. 先写 O：一句话说清「这个周期我们要去哪」，避免堆功能。
2. 每个 O 配 2–5 个 KR：可量化（数字 / 百分比 / 完成度），有基线值和目标值。
3. KR 不是任务：KR 衡量结果，任务另行拆解，别把「上线 X 功能」当 KR。
4. 周期末打分：按 0–1（或 0–100%）评分；0.6–0.7 是健康区，1.0 说明目标定低了。
5. 公开透明：所有人能看到彼此 OKR，对齐依赖。

## 失败模式

- O 写成功能列表，没有方向感。
- KR 不可度量（「提升体验」），打分靠感觉。
- 定了不跟踪，周期末才想起。
- 把 KR 当绩效考核，引发保守目标。

## 验证证据

- 周期末有打分记录。
- O 与上层目标有可追溯的对应关系。
