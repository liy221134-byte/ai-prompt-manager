# 路线图：把目标排到时间轴上

## 核心结论

路线图是「什么时候交付什么价值」的方向图，按价值 / 周期粗排，不承诺精确日期；
细节留给排期。它是沟通工具，不是合同。

## 使用条件

- 对外（老板 / 客户 / 干系人）沟通方向。
- 多版本串行时确定先后顺序。

## 不适用场景

- 替代详细排期——路线图不画每日任务，细节在排期里。

## 执行方法

1. 按价值（机会分 / ICE）把主题排进未来 2–4 个周期。
2. 每格写「解决什么问题 / 交付什么能力」，不写功能清单。
3. 越远越粗：下一周期可较细，之后只到主题级。
4. 标注依赖与不确定性（技术风险、外部依赖）。
5. 每季度滚动更新，过期项明确移出或顺延。

## 失败模式

- 排成甘特图承诺死日期，一旦变动就失信。
- 把路线图当合同逐项对账。
- 从不更新，变成摆设。

## 验证证据

- 干系人能一句话说清「接下来两个周期做什么」。
- 路线图与 OKR 对得上。
