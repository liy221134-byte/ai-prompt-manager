# 会议纪要：决策与待办留痕

## 核心结论

会议价值在结论与行动项，不在记录全文。纪要把「定了什么、谁何时做、未决什么」写清即可。

## 使用条件

- 任何有决策或分配任务的会议。

## 不适用场景

- 纯信息同步——用文档 / 公告代替开会。

## 执行方法

1. 会前定议程与目标，避免跑题。
2. 纪要四段：结论 / 行动项（负责人 + 截止日）/ 未决问题 / 下步。
3. 当天发出，相关人可补充。
4. 行动项进跟踪系统，不靠纪要本身提醒。
5. 无结论的讨论标注「待 X 前定」，不悬空。

## 失败模式

- 记流水账无人看。
- 有讨论无行动项。
- 行动项无期限，不了了之。

## 验证证据

- 会后 24h 内发出。
- 行动项可追溯到负责人与截止日。
