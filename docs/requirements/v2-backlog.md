# 2.0 需求池
> 状态：早期想法池。正式需求以 [2.0 需求草案](v2-requirements-draft.md) 为准。
>
> 说明：本文件保留早期设想。与草案冲突时以草案为准，特别是 2.0 不替代专业
> 智能体生成完整 PRD，也不建设实时监控或数据库运维平台。


## 产品方向

2.0 从“AI 提示词资产管理工具”扩展为：

> 面向零代码 AI 开发者的个人开发资产工作台。

核心资产不只包含提示词，还包含：

- 项目规则。
- PRD。
- 技术决策记录。
- 验收清单。
- 数据库说明。
- 部署与回滚方案。
- 提示词包和开发模板。

## 核心闭环

```text
创建项目
-> 生成项目文档体系
-> 选择开发提示词包
-> AI 辅助需求和开发
-> 记录决策与验收
-> 发布和沉淀模板
```

## P0：2.0 必须完成

### 项目工作区

- 创建多个项目。
- 每个项目拥有独立提示词和文档。
- 显示项目阶段、技术栈和当前版本。

### 文档中心

支持以下文档类型：

- PRD。
- ADR。
- 验收清单。
- 数据库结构。
- 环境变量清单。
- 发布与回滚。
- 备份策略。
- FAQ。

### 文档模板

- 新建文档时选择模板。
- 支持变量占位符。
- 支持复制、编辑、归档和导出。
- 模板跟随版本记录。

### 开发提示词包

首批内置：

- 需求拆解。
- Bug 描述模板。
- 验收清单生成。
- PRD 快速生成。
- AI 代码审查。
- 开发规则与协作提示词。

### 文档与提示词关联

- 文档可以引用提示词。
- 提示词可以标注服务的项目阶段。
- 执行提示词后可以生成或更新文档草案。

## P1：智能化

### AI 生成文档

- 根据产品想法生成 PRD。
- 根据 PRD 生成开发任务。
- 根据功能生成验收清单。
- 根据数据库生成结构说明。
- 根据发布记录生成变更日志。

### 文档同步助手

- 检测产品范围变化。
- 提示哪些文档需要更新。
- 展示旧文档和新文档差异。
- 用户确认后再更新。

### 需求追踪

- 需求与提示词关联。
- 需求与验收项关联。
- 版本与发布记录关联。
- 显示未覆盖的验收项和未完成需求。

### 项目导出包

一次导出：

- 提示词。
- 文档。
- AGENTS.md。
- README。
- START_PROMPT。
- 路线图和验收清单。

导入后直接建立完整项目基础。

## P2：协作与扩展

- 团队工作区。
- 文档评论和审核。
- 提示词共享和发布。
- 项目模板市场。
- 浏览器采集插件。
- GitHub 仓库和项目文档双向同步。

## 2.0 数据模型影响

需要新增：

- `projects`
- `documents`
- `document_versions`
- `prompt_collections`
- `prompt_pack_items`
- `document_prompt_links`

`prompts` 表需要增加可选的 `project_id` 和 `collection_id`。

## 风险

- 功能范围从提示词工具扩展到文档和项目管理系统。
- 文档编辑器和版本差异会增加开发复杂度。
- 多项目会改变当前单库数据模型。
- AI 文档同步需要严格的人工确认。
- 2.0 不应破坏 1.x 的快速使用体验。

## 不进入 2.0 的功能

- 在线代码执行。
- 自动化部署第三方项目。
- 复杂团队审批流。
- 公共提示词交易平台。
- 完整项目管理替代品。
