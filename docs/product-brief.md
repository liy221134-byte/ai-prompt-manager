# 产品范围

## 产品定位

面向个人用户的 AI 提示词资产管理工具，核心闭环为：

```text
采集 -> 结构化 -> 分类 -> 检索 -> 使用 -> 优化/合并 -> 版本沉淀
```

## 目标用户

产品经理、开发者或内容创作者等需要长期积累和重复使用 AI 提示词的个人用户。

## 第一版范围

### 必做能力

- 浏览提示词卡片
- 新增、查看、编辑和删除提示词
- 使用 Markdown 保存和展示正文
- 主分类和多个标签
- 关键词搜索和基础筛选
- 识别并填写变量
- 一键复制最终提示词
- 导入和导出提示词
- 本地数据持久化和备份
- AI 自动识别结构、摘要和标签建议

### 延后能力

- 用户注册和登录
- 多设备同步
- 团队空间、评论和审核
- 浏览器插件
- 提示词市场
- 直接调用模型执行提示词
- 成熟的多提示词 AI 合并

用户系统只有确认存在多设备同步或多人协作需求后才加入。

## 提示词数据结构

第一周静态卡片直接采用最终字段结构，避免后续重做数据模型。

### 必须字段

| 字段 | 用途 |
| --- | --- |
| `id` | 唯一标识 |
| `title` | 卡片标题 |
| `category` | 主分类 |
| `tags` | 多个检索标签 |
| `content` | Markdown 格式的提示词正文 |
| `useCase` | 适用场景 |
| `createdAt` | 创建时间 |
| `updatedAt` | 更新时间 |

### 后续字段

- `summary`：AI 生成的简短摘要
- `variables`：从正文识别的变量
- `isFavorite`：收藏状态
- `collectionId`：所属集合
- `source`：来源类型和原始内容
- `versions`：历史版本
- `mergedFrom`：AI 合并来源

## 核心流程

### 使用提示词

1. 通过分类、标签或搜索找到提示词。
2. 打开卡片并识别变量。
3. 填写变量并实时预览最终内容。
4. 一键复制。
5. 用户将内容粘贴到目标 AI 工具中使用。

### 采集提示词

1. 用户粘贴原始文本。
2. AI 识别标题、正文、分类、标签和适用场景。
3. 用户检查并修改识别结果。
4. 用户确认保存。
