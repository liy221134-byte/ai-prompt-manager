## 我这边另发现、它没提的一条

WorkBuddy 的自述格式核实里没有 Codex 那一格（它明说「由 Codex 侧确认」）。已补：

- Codex 插件清单是 **`.codex-plugin/plugin.json`**，技能目录由清单里的 `skills` 字段指向（如 `./skills/`）；
- Codex 会加载插件的 `<插件>/skills/<技能名>/SKILL.md`，在会话里显示为 `插件名:技能名`
  （本机实证：`vercel:agent-browser`、`figma:figma-use`）；
- 项目级技能位置：`.agents/skills/`（本机技能根之一就是 `C:/Users/90402/.agents/skills`）与
  `~/.codex/skills/`——前者与 Cursor 共用同一个位置。
