# 8 周路线图

> 本文随产品演进。下面分三块：v1 阶段是历史、2.0 已收口、v2.25.0 在进行中、v3 待确认。
> 版本与验收清单见 [文档索引](INDEX.md) 的「验收与测试」一节。

## 历史：v1 阶段（纯提示词库）

早期八周做的是「个人 AI 提示词库」：静态卡片、本地管理、变量、备份、AI 采集与合并、垃圾箱、
生产加固、发布准备。这一阶段的产品范围见 [产品范围](product-brief.md) 的「历史」说明——
当时产品只管提示词。

| 阶段 | 主题 |
| --- | --- |
| 第 1 周 | 项目基础与静态卡片（v0.1.0） |
| 第 2 周 | 本地提示词管理 |
| 第 3 周 | 数据安全与迁移层 |
| 第 4 周 | 本机共享数据库 |
| 第 5 周 | AI 采集能力 |
| 第 6 周 | AI 合并与垃圾箱 |
| 第 7 周 | 生产加固 |
| 第 8 周 | 发布准备 |
| v0.9.0 | 提示词 AI 优化 |
| v0.9.1 | 变量管理 |
| v1.0.0 | 整体收尾 |

## 2.0 阶段（已收口，截至 v2.24.0）

把「提示词」扩成统一资产底座，三条链路走通：提示词链路、项目文档六段链路、代码链路。
支撑能力：规则编译、项目图谱、工程导入、本机 MCP、质量等级与工程基线、验收证据链、
发布门禁与回滚、沉淀回流、立项起步包、本地与云端定期同步、规则引用模型。
收口结论见 [2.0 收口清单](2.0-closeout.md)。

| 版本 | 主题 |
| --- | --- |
| 2.0.0～2.1.2 | 统一资产底座、提示词写入路径、文档包导入与元数据、技术档案与关系、备份 v2 |
| 2.2.0～2.4.0 | 规则包与种子资产包导入、规则编译、模板中心 |
| 2.5.0～2.7.0 | 项目图谱与影响分析、工程导入、本机 MCP |
| 2.8.0～2.11.0 | 质量等级与工程基线、验收证据链、发布门禁与故障演练、统一加固 |
| 2.12.0～2.16.0 | 交互重构、文档与模板边界、Spec 层、关联录入、沉淀回流、立项起步包、MCP 批量入库 |
| 2.17.0 | 项目资产两条链路：文档视图与代码视图 |

| 2.19.0 | 本地与云端定期同步 |
| 2.20.0～2.24.0 | 规则引用收尾、关联录入补齐、技术上下文筛选、项目规模筛选、本机 MCP 接入 |

## 明确冻结的能力（不是漏做）

- 团队协作、评论、审批、多租户权限：产品定位是个人使用。
- 规则冲突自动解决、完整协作路径生成、代码与数据库完整图谱：延后评估。
- 自动修改外部 GitHub 仓库、自动部署执行。
- 真实浏览器端到端测试与 CI 门禁（工程能力练习里手动做）。
