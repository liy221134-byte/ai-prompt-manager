# 8 周路线图

## 第 1 周：项目基础与静态卡片

- 初始化 Git
- 建立项目规则和产品文档
- 建立 Next.js、TypeScript 和 Tailwind CSS 项目
- 按最终字段结构展示 3 张静态提示词卡片
- 完成桌面端和移动端验收
- 发布版本标签 `v0.1.0`

## 第 2 周：本地提示词管理

- 新增、编辑、删除提示词
- Markdown 编辑和预览
- 变量识别
- 本地浏览器持久化

## 第 3 周：数据安全与迁移层

- 导出全部提示词为带版本号的 JSON 备份
- 检查备份文件格式并阻止无效数据写入
- 导入前预览新增、更新和跳过结果
- 冲突时保留更新时间较新的版本
- 导入时只合并，不删除本机已有提示词
- 记录最近一次备份时间
- 为备份格式、冲突和合并逻辑建立自动化测试

## 第 4 周：本机共享数据库

- 使用本机 SQLite 保存提示词
- 本机 API 提供读取、新增、更新、删除和合并能力
- 不同浏览器共享同一份数据
- 旧 `localStorage` 数据迁移前显示合并预览
- 服务器重启后验证数据持久化
- 数据库文件从 Git 中排除

## 第 5 周：AI 采集能力

- 粘贴原文
- AI 识别正文结构
- 生成分类、标签和适用场景建议
- 用户确认后保存

## 第 6 周：AI 增强与版本记录

- AI 摘要和标签优化
- AI 合并测试版
- 版本记录和差异查看

## 第 7 周：生产加固

- 自动化测试和错误处理
- 数据备份和恢复
- 安全检查和访问保护
- 日志和基础监控

## 第 8 周：发布

- 数据备份和恢复
- 日志和基础监控
- 正式部署
- 回滚方案
- 发布说明和复盘
