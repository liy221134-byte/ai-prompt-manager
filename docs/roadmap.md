# 8 周路线图

## 第 1 周：项目基础与静态卡片

- 初始化 Git
- 建立项目规则和产品文档
- 建立 Next.js、TypeScript 和 Tailwind CSS 项目
- 按最终字段结构展示 3 张静态提示词卡片
- 完成桌面端和移动端验收
- 发布版本标签 `v0.1.0`

## 第 2 周：本地提示词管理

- 新增、编辑、删除提示词
- Markdown 编辑和预览
- 变量识别
- 本地浏览器持久化

## 第 3 周：数据库基础

- 建立数据库
- 设计最终数据表和迁移
- 完成提示词读取
- 保持本地开发环境可独立运行

## 第 4 周：持久化 CRUD

- 提示词新增、编辑、删除真实落库
- 分类、标签和收藏
- 导入和导出
- 加载、空状态和错误状态

## 第 5 周：使用流程优化

- 关键词搜索
- 分类和标签筛选
- 变量填写和实时预览
- 一键复制和复制反馈

## 第 6 周：AI 采集能力

- 粘贴原文
- AI 识别正文结构
- 生成分类、标签和适用场景建议
- 用户确认后保存

## 第 7 周：AI 增强与生产加固

- AI 摘要和标签优化
- AI 合并测试版
- 版本记录和差异查看
- 自动化测试、错误处理和安全检查

## 第 8 周：发布

- 数据备份和恢复
- 日志和基础监控
- 正式部署
- 回滚方案
- 发布说明和复盘
