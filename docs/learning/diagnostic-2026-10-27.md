## 二、先泼三盆冷水：这份结果的可靠性有边界

**不把边界说清，后面的校准就是自欺欺人。**

### 边界 1：简答题 0/9，这一项主导了结论

9 道简答题一道要点都没勾。这有两种可能，含义完全不同：

- **真的写不出来** → 那 S2 的 L3/L5、S6 的 L3/L4/L5 就是真实水平为 0。
- **写了但没勾要点** / 时间不够没做 → 矩阵系统性偏低，S2 和 S6 被严重误判。

**两种可能我不能替你判断，所以按最保守的口径算：当 0 分。** 理由不是悲观，是考试口径——
应用技术科目 4 道大题全是主观题，写不出来就是 0 分，不会因为「其实我懂」给分。

**这条如果你要改口，直接说，我把 S2/S6 的工时下调 15—20 小时。**

### 边界 2：单题模块让「未过 L1」噪声很大（我的设计问题）

- S4 的 L1 只有 1 道题，错一题就判「未过 L1」；
- S6 的 L1 只有 2 道题，对 1 道就判「未过」。

**但 S4 的 L2 和 L4 都是 1/1 全对。** 一个人 L1 概念题错、却在 L2 和 L4 都对，
最合理的解释不是「未过 L1」，而是**那一道 L1 题恰好是没背准的那个点**。

⇒ 这不是你的问题，是**我卷子的题量分配不均**。M1 的题库必须做到「每模块每层 ≥3 题」才允许做层级判定，
否则就是这个结果。**这条已写进 M1 Spec 的硬约束。**

### 边界 3：样本量

S4 只有 3 题、S6 只有 2 题客观。这两个模块的一切结论都只能当「方向参考」，不能当结论用。

## 三、四个真发现（这些比分数有用）

### 发现 1：**最大的风险不是知识缺口，是「写不出来」**

客观题 19/31 = **61%**，恰好压着 60% 的及格线。
简答题 0/9 = **0%**。

而中项两科里：基础知识（75 单选）你能靠认题蒙到及格线边缘；**应用技术（3 简答 + 1 计算）
全是主观题，写不出过程就是 0 分**。

**按现在的状态上考场，最可能的结果是：上午过、下午挂，而且挂得没有悬念。**

这跟「再多学 380 小时知识」是两件事。知识够了但写不出来，照样不过。所以 v4 的练习设计里，
**「写出过程」的权重必须高于「选对答案」** —— 这一条要落到 M1 的题型配比和 M3 的连续拷问里。

### 发现 2：S3 不是零基础，`expected_gap` 的预判错了

主题包原来给 S3 信息技术基础打 `expected_gap: 5`（空白），并按 130 小时（全场最多）排。
实测：**客观题 6/9 = 67%，与 S1 持平；而且 L4 场景题（等保定级）1/1 全对。**

原因不难理解：你做产品经理，碰过云、等保、数据治理、数据流通这些真实项目。
**你是「接触过但没系统学」，不是「空白」。**

这 130 小时的假设如果不改，等于把最不缺的地方当成最缺的地方砸时间 —— 这正是调研报告批评的那个错。

### 发现 3：错题高度同质 —— 全都错在「精确性」上

逐题看错的 12 道客观题，类型惊人一致：

| 错在哪 | 题 | 特征 |
| --- | --- | --- |
| 分类边界 | 十大知识领域（S1-L2） | 记不全，把监理的「四控」混进来 |
| 术语精确 | 质量保证 vs 质量控制（S2-L2） | 两者归哪个过程组记混 |
| 指标含义 | CPI/SPI（S2-L2）、SV 含义（S2-L1） | 公式记混 |
| 层级数量 | 监理四控（S4-L1） | 和项目管理的四要素混了 |
| 法律性质 | 中标通知书（S5-L2） | 要约/承诺记反 |
| 标准层级 | 团标/企标（S5-L2） | 强制性 vs 推荐性 |

**共同点：没有一个错在「不理解」，全都错在「没有精确标准答案」。**

这跟发现 1 是同一个病的两面：**你有大量真实的项目直觉，但软考考的是标准表述**。
直觉在案例分析里是优势，在选择题里是陷阱——因为「我觉得应该是这样」往往不是教材的写法。

⇒ 备考策略要变：**不是「从零学」，是「把已有的直觉校准到标准答案」**。
前者要 380 小时，后者不需要。

### 发现 4：L4 场景判断反而是你的强项

S2 的 L4 两题全对（变更场景找主次、收尾过程组），S3 的 L4 也全对（等保定级），
S4 的 L4 也对（监理第三方角色）。

这符合你的背景：**给一个真实场景做判断，你比刚入行的人强得多。**
所以 S2 的工时不该全砸在「理解五大过程组」上，而应该砸在「把过程组的标准说法背准」+
「把案例题写成能给分的结构」上。

## 五、对接下来三件事的影响

1. **M1 的题库配比**：S2 和 S6 要加「过程题」（写流程、写计算过程），不能只有单选。
   每模块每层 ≥3 题，否则层级判定不可用（见边界 2）。
2. **M1 的页面优先级**：先做「按层级出题」，矩阵展示可以晚半版——因为你现在最缺的不是看矩阵，
   是练「写出来」。
3. **M3 的连续拷问**：要能出「请写出完整计算过程」这种题，而不是只出选择。
   否则练到最后还是「认得但写不出」。
