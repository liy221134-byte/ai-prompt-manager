## 验收标准

1. **入口并列**：首屏顶部与「公共资产 / 文档 / 代码」并列出现「采集台账」入口；本地模式与云端模式都出现（练习题库仍只在云端出现）。
2. **台账全量**：`/external-sources` 列出全部来源，行数 = `seed-packs/external-sources/README.md` 第六节台账行数（当前 23）。
3. **抽屉字段一致**：点开任意一行，抽屉里的 来源链接 / 类型 / 状态 / 处置结论 / 落到哪条资产 / 核实日期 与 README 对应行逐字段一致。
4. **落点追溯**：「落到哪条资产」若已匹配到库内资产，抽屉显示资产标题并可打开该资产详情；未匹配到时显示原文，不报错。
5. **是否编译不谎报**：按第三节规则标注——候选/知识库资产显示「未编译／候选」或「知识库资产」，不显示「已编译」。
6. **合规检查可用**：`npm run check:leads3-compliance` 扫出全部外部来源资产并列出违反四约束的项；当前 9 个 M0 资产 **0 违规**。
7. **全只读**：采集台账视图内不出现任何新增／编辑／删除入口（无写操作按钮）。
8. **边界与幂等**：台账某行缺字段时视图显示「—」不崩；台账解析不到表格时生成脚本报错退出；生成脚本连跑两次产物无差异（幂等）。

## 已知限制（待决策）

- **落点未登记文档资产**：台账第六节的「落到哪条资产」列登记的是种子包规则 ID（`RULE-*`／`PLAYBOOK-*`／`MTH-DESIGN-GATE-*`）或模板路径，**没有登记 M0 落库的 9 个文档资产**（`MTH-TEAM-OKR-001` 等）。所以第 4 条「打开资产详情」的深链机制**当前数据下不会触发**；机制已就绪（生成期已把 9 个规范 ID 建索引、抽屉里已带跳转按钮），把文档资产补进台账落点列即可生效。
- **是否编译是简化推导**：按库内资产状态推导，不解析 `AGENTS.md` 正文做精确比对（精确比对留到后续版本）。当前外部资产全部是候选/知识库，「已编译候选」档为 0。
- **合规检查走终端**：检查要读本机库，云端模式浏览器读不到库，所以视图里的按钮是「命令提示入口」，真实执行在终端；退出码 0/1 便于接进别的检查。
- **A 方案的上限**：视图是 README 的只读镜像，改台账后要重跑 `npm run generate:leads3-ledger`；`tests/external-sources-ledger.test.mjs` 会比对 JSON 与 README，忘了重跑会被测试挡下。
- **构建环境**：`npm run build` 在本工作环境跑不起来（工作区 node_modules 是指向项目根之外的符号链接，Turbopack 拒绝；主检出受批量删除守卫限制），非代码问题。本次改动只新增 `src/app/external-sources/` 路由与组件、两个纯逻辑模块、两个脚本和一份 JSON，不改变既有构建产物结构；类型检查与测试已覆盖。
