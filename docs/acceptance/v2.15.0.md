## 验收标准

- [x] 工程基线里能看到「建议从公共库装这些」清单，每条有推荐理由；
      点「把这 N 条装进项目」后，装进去的条目从清单里消失。
      依据：`tests/project-kickoff.test.mjs`「推荐：硬约束规则优先，已经装过的不再推荐」。
- [x] 推荐里**不推公共库的实例文档**，只推规则、模板和方法级参考。
      依据：同文件「推荐：模板会带上，公共库的实例文档不会往项目里推」。
- [x] 「立项与交付」面板里有四条提示词（PRD／Spec／技术档案／验收清单），
      每条能复制，内容包含项目名和项目说明。
      依据：同文件「立项提示词：四份产物都在」。
- [x] 能下载开发体系包，文件按规则／文档／模板分节，只有当前项目的内容。
      依据：同文件「交付包：按规则、文档、模板分节，文件名带项目名」。
- [x] 「存成项目里的一份文档」后，项目文档里出现这份包（同名时更新，不重复建）。
      依据：`handleSaveDeliveryPack`（走与保存文档同一条路径）。
- [x] 同一个项目第二次编译同一产物走**更新**，不新增同名文档，旧内容在版本记录里。
      依据：`handleSaveCompiledDraft`（同名 + 角色「编译结果」时走更新）。
