## 一、这一版做了什么

目标上多存一份「阶段定义」（四段：启动期 / 基础期 / 强化期 / 冲刺期，每段带起止日与一个可选里程碑），
今日计划据此多显示一行：`启动期 · 第 1 周 / 共 8 周 · 距「摸底模考」还有 7 天`。

设置弹窗里能改这份定义，也有一个「按目标日期自动切分」的按钮。

**不做阶段门禁**：不到基础期就不让做某个模块的题。阶段日期是估算，模块工时也是估算，
两个估算互相约束只会放大误差；更要紧的是它会把「今天有空想多学」变成「系统不让」。
今日计划的语义是建议，不是许可。

**不存「当前在第几段」**：由日期现算。存了就得每天维护，算出来永不落后。

**不与模块摊派做强一致校验**：阶段是人的外框，模块窗口是按工时分的内框，错开是常态。
每日弹一条「阶段与模块不一致」等于噪声。

## 三、五条关键决定

1. **阶段只影响展示，不参与排题。** 这条写死在 `daily-plan.ts` 的 `phases` 注释里，并有一条
   `deepEqual` 的防回归测试盯着。理由：阶段日期是估算，拿估算去改题单，
   等于让一个猜出来的日期决定今天做几道题。

2. **自动切分切的是比例，不是日期。** 8:8:9:5 这个比例来源可查（2026-10-28 读到的飞书「备考周计划」表
   就是 8/8/9/4+1 周，共 30 周），但**那张表的日期一个都没抄**——它是 30 周的高项排布，
   中项到 2027-05-22 只有约 28.6 周，抄日期等于把别人的日历套到自己头上。

3. **缝里不返回 null，归到前一段并标 `after`。** 归一化只保证按日期排序，**不保证首尾相接**——
   阶段是人的外框，允许留空档（比如考完等成绩那两周）。缝里返回 null 会让整行在某一天突然消失，
   让人以为功能坏了。

4. **单段脏数据丢掉那一段，不整份作废。** 四段里有一段缺日期，丢三留一还能用；
   整份作废等于因为他手滑少填一个格子，功能整个消失。

5. **校验只在弹窗里做一次，不写两处。** `saveSettings` 把归一化过的数组原样存，
   不在那里再归一化一遍——同一套规则写两处，改一处忘一处就会「弹窗说没问题、存进去却是另一份」。

## 四、与 spec 的一处偏差（有意为之）

spec §2.3 写的是「没有 `target_date` 时按钮禁用，并说明『先设目标日期』」。
实现改成了：**`target_date` 留空时用主题的官方 `deadline` 作为终点**，两者都没有才拒绝并提示。

理由：今日计划自己就是用 `endsAt: goal.target_date ?? topic.deadline` 作终点的。
主题的官方考试日不是猜的，是主题自带的事实；而这一版里他的 `target_date` 正好是空的
（截止日取自 `topic.deadline`），按 spec 原文的话按钮会一直灰着，
功能在这台机器上等于不可用。**原则（不凭空造日期）仍然守住了**，只是把「主题官方日期」
也算作事实来源。

## 五、已知缺口

1. **自动切分会覆盖手填的里程碑。** 因为它是「按目标日期重新切一份」，整份替换。
   实测中就发生过一次：给第一段填了「摸底模考」，改目标日期再切，里程碑没了。
   现在没有二次确认——判断是「保存前随时可以取消离开」，成本可控。真让人踩疼了再加提示。

2. **只有 4 段模板，不能自定义段数。** 手加/移除段是支持的（0—8 段），
   但没有「5 段」「3 段」这类模板。spec 明确把「多套阶段方案、模板库」列为不做，
   等真出现第二种节奏再说。

3. **阶段与模块窗口没有任何联动。** 界面上同时存在「启动期第 1 周」与「项目管理框架（第 1—49 天）」，
   两者对冲时不会提示。这是刻意的不做，理由见第一节最后一条。

4. **`key` 字段目前没有消费者。** 自动切分产生 `kickoff / foundation / intensive / sprint`，
   手加段退化成开始日。留着是为了「改了日期它也不变」这个稳定性，将来要做分段统计
   或里程碑历史时可以直接用。现在它只存不读——**如果下一版还用不上，应该删掉**，
   免得又变成一栏空跑的东西。

## 六、怎么自己验

```
cd /e/codeX项目 && npm run dev
```

打开 `http://localhost:3000/learning/rk-mid-integration`：

1. 今日计划标题下方应有一行 `启动期 · 第 1 周 / 共 8 周`（这是我实测时切的那份，已落库）
2. 点「改设置」→ 看到四段卡片，日期可改、可加里程碑、可移除
3. 点「按目标日期自动切分」→ 四段日期按比例重排，收在目标日
4. 改第 2 段的开始日到它结束日之后 → 保存被拒，红字指出第 2 行
5. 把四段全移除再保存 → 阶段行消失（不显示「未设置」）
