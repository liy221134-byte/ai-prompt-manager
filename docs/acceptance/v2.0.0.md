# v2.0.0 验收清单（手工版）

## 怎么用

- 版本：`v2.0.0`，对应提交 `e5be870`，标签 `v2.0.0`。
- 在浏览器里逐条点一遍，能对上就在方框里打勾。
- 这里只列**需要你在界面上判定**的项目，自动化结果放最后一节，不占签字项。
- 完整验收标准见 [2.0.0 项目与统一资产底座设计](../superpowers/specs/2026-09-21-v2.0.0-asset-foundation-design.md)。

## 一、原有提示词不受影响（先过这一节）

- [ ] 打开首页，默认项目下仍是 3 条提示词，标题和正文与升级前一致。
- [ ] 打开任意一条详情，填写变量后能一键复制，复制出的内容是替换后的文本。
- [ ] 新增一条提示词，刷新页面后仍然存在，数量加 1。

## 二、项目工作区

- [ ] 新建一个项目，新项目下各类型计数都是 0。
- [ ] 切回默认项目，3 条提示词恢复显示。
- [ ] 打开项目设置，改名称和阶段，保存后顶部标题和项目列表同步更新。
- [ ] 归档当前项目，提示词仍然可见；重新激活后项目回到「进行中」。

## 三、规则和文档

- [ ] 在「规则」标签下新增一条规则，保存后自动打开详情，版本记录显示第 1 版。
- [ ] 编辑这条规则改正文，版本记录变成第 2 版。
- [ ] 展开第 1 版并点「恢复这一版」，确认后出现第 3 版，第 1 版和第 2 版都还在。
- [ ] 归档这条规则：活跃列表里消失，状态筛选切到「已归档」能找到，点「重新激活」后回到活跃列表。
- [ ] 在「文档」标签下新增一条文档，文档类型和状态与填写的一致。

## 四、优化回退

- [ ] 选一条提示词做一次 AI 优化并保存，详情里出现「可以回到优化前」。
- [ ] 点「回到优化前」并确认，标题和正文回到优化前，提示消失。

## 五、数据安全

- [ ] 打开「数据管理」，确认提示明确写出：当前备份只包含提示词，规则和文档不在范围内。

## 六、云端（要先把 Supabase 迁移应用上去，做完再勾）

- [ ] 登录后能看到默认项目和原有提示词。
- [ ] 新建项目、新增规则能保存，刷新后还在。
- [ ] 换一个账号登录，看不到上一个账号的项目和资产。
