- [x] 项目里任意规则／文档／模板／图谱节点能「提升为公共资产」，公共库出现同名副本，

- [x] 提示词提升时给出原因（它本来就是账号级），不重复提升已提升过的条目。
      依据：同一条测试。
- [x] 公共库那份更新后，打开项目里这条会看到「公共库那份在这之后改过」的提示与两个按钮。
      依据：同一条测试的「上游状态」部分。
- [x] 「看差异」能看正文行级差异（复用提示词优化的差异视图）。
      依据：`src/components/sediment-diff-dialog.tsx` 复用 `diffPromptLines`。
- [x] 「拉取公共版本」产生一条新版本，旧正文可从版本记录恢复。
      依据：走 `buildUpdateAssetInput`（与手动保存同一条路径）。
- [x] 沉淀体检在公共资产 → 更多里，三类线索都能列出来，且不自动做任何动作。
      依据：`tests/sediment-flowback.test.mjs`「沉淀体检」。
- [x] 全流程不删除任何数据；本机与云端共用同一套纯逻辑与契约测试。
      依据：同一条测试 + 契约测试。
