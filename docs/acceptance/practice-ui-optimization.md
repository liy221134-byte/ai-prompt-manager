# 云端题库交互优化 验收清单

关联设计：`docs/practice-interaction-optimization-design.md`（线索 4 题库模块）
待并入正式发布版本的验收清单（本文件为工作稿）。

## 验收标准

1. **入口平级**：云端模式下，首屏与「公共资产 / 项目资产」并列出现「练习题库」tab；本机模式（非 supabase）下该 tab 不出现。
2. **类型筛选**：练习首页顶部「习题类型」一行，选项来自 `practice_questions.type` 的去重值（含 单选/多选/判断/实操）；切换后与状态可叠加过滤。
3. **状态筛选**：「习题状态」一行含 全部 / 未做 / 已做 / 错题；切换后列表实时过滤：
   - 未做 = 本人 `practice_attempts` 无该题记录；
   - 已做 = 本人有该题作答记录；
   - 错题 = 本人该题有 `is_correct = false` 记录。
4. **两栏布局**：进入答题页后为左树 + 右答题两栏。左侧树按 `category` 分组，每条带状态色点，点击可跳到任意题；右侧为题干/选项/提交区。
5. **对错反馈**：提交后明确显示「回答正确 / 回答错误」（正确绿、错误红），并给出解析；多选额外列出正确项。错题在树与列表标记红色（红点）。
6. **上下切换**：答题页底部有「上一题 / 下一题」，可在题目间任意切换；到首/末题时对应按钮禁用。
7. **列表呈现**：题库列表按 `category` 分组；每条题左侧色点表示作答状态（灰=未做、绿=已做、红=错题），右侧显示「类型 · 难度」。
8. **功能保持**：全部随机练习、错题重练、练习本类、单题 在加筛选后仍然可用；随机练习遵循当前筛选（无筛选则为全量）。
9. **无重复入口**：原「更多」菜单里的「练习题库」已移除，不与新 tab 重复。
10. **自动化门禁**：`npm run check:fast` 通过（类型检查 + 测试无报错）。

## 已知限制（待决策）

- 状态筛选依赖本人登录态；未登录时所有题按「未做」处理，登录后状态才生效。
- 判断题在答题页以「正确 / 错误」两个单选选项呈现（题型标签显示「判断」），属合理简化，未单独做判断题专用 UI。

## 验证方式

- 自动化：`npm run check:fast`。
- 浏览器（需云端模式 + 登录）：访问首屏确认 tab；进入 `/practice` 切换两类筛选、点单题进入两栏页、提交看对错反馈与解析、用上一题/下一题切换；用另一账号或清记录验证 未做/已做/错题 区分。
