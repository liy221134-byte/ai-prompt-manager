# v2.21.0 验收清单（图谱节点直接关联文档）

## 版本目标

把「节点 ↔ 文档」这条链路的入口补齐：能从一个图谱节点直接挂一份文档，
并把这个动作和它产生的关系在界面上说清楚。

## 做什么 / 不做什么

**做**：

1. 图谱里选中一个节点时，能直接选一份项目文档挂上去（不再只能「一份文档挂多个节点」）。
2. 说清「这个节点指向谁」列的就是资产关系，图谱的「谁指向它」「间接影响」顺着这批关系算。
3. 节点编辑器的「资产关系」区补一句说明，指出挂文档该往哪加。

**不做**：

1. 不改资产关系的数据结构，不新增表、字段或迁移。
2. 不改「批量挂文档」的行为，只把两边的判定收到一个函数里。
3. 不动待排期第 3 条（验收记录关联录入）——它还缺一次决定，见下。

## 未完成事项与风险

1. **待排期第 1 条其实早就做完了**：工程基线的缺口行在 v2.13.0 就有「或用已有」下拉，
   文档满足了显示「打开」，不需要新建。本次核对后没有改代码。
2. **待排期第 3 条（验收记录关联录入）只做了一半**：文档型验收记录可以靠「关系」区指向需求节点，
   但没有老验收记录类型那种「对应需求节点」选择框。要不要补，先定一件事：
   一个验收记录只对应一条需求，还是允许一份清单覆盖多条需求（现有覆盖统计两种都认）。
   定了再动，否则会做出跟覆盖统计不一致的界面。
3. 每个节点只能看到自己当前类型的树；挂文档的范围是「当前项目的活跃文档」，跨项目不行。
