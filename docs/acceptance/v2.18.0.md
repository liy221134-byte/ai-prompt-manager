## 验收标准

- [x] 项目引用包后，规则列表里出现这个包在公共库里的全部成员，带「公共库 · 包名」角标。
      依据：`tests/rule-reference.test.mjs`「项目引用了包：公共库里的成员跟着进来，并标出包名」。
- [x] 项目里那份老副本与公共库正本重复时只显示一次。依据：同文件「只显示公共库那份」。
- [x] 公共库里没有这份包的正本时，项目自己那份留着。依据：同文件「项目自己那份留着」。
- [x] 装到项目走引用模式：规则成员不复制。依据：`tests/rule-pack-install.test.mjs`
      「引用模式：只装包这条引用，规则正文留在公共资产库」。
- [x] 规则编译候选集包含引用来的规则。依据：`listCompileCandidates` 新增的 `referencedRuleIds`。
- [x] 项目专属规则不受影响（仍然能编辑、能提升为公共资产）。
      依据：`listProjectOnlyRules` 与沉淀体检口径不变。
- [x] 本机实测：项目规则 28 条（全部来自公共库引用：工程方法 20 条 + 操作者训练 8 条），
      项目专属 0 条；链路完整性四环全绿；最近一次发布显示 v2.17.0（进行中，门禁 0/2）。
