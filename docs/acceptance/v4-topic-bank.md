## 四、顺带修掉的一个问题：答案扎堆在 B

补题时发现整个题库**答案严重偏斜**：单选 131 道里 B 占 73 道（56%）、D 只有 6 道（5%）。
这不是这次新题才有的问题，旧题同样如此——学生做几套就能摸出「不会就选 B」。

已做重平衡，做法是**只交换正确项与目标位置项的文本**，其余两个选项位置不动：

- 改动 36 道，答案位置分散到 A/C/D
- 只挑**解析里不含「A 」「B 」这类字母引用**的题改，避免解析指向错位
- 改完硬校验：每题的**选项集合**与改动前完全一致、**正确答案的文本**完全一致，
  通过 31 题（其余 5 道是本次新增，旧版无对照）

结果分布：**A 33 / B 37 / C 33 / D 28**（原 24 / 73 / 28 / 6）。
第二批 50 道新题按「A、B、C、D 轮流排」写，改完是 **A 43 / B 47 / C 43 / D 37**，仍未回到扎堆。

一条没法自动化的部分：值不值得为了分布打乱选项的「自然顺序」（如数值从小到大）。
这次也打乱了，理由是真卷选项本就不按大小排，学生不该靠顺序蒙。

## 九、第四批：S8 单题格补到每格 2 题

### 为什么补

上一批结束时 S8 有 70 道题分散在 35 格上，其中 **34 格只有 1 题**——
同一知识点同一层级再练一次会出同一道题。这在新题上有个直接证据：
练习页底部会显示「同类随机再抽（N）」，N=1 时点下去还是原题。

补的判据跟第二批一样：**每格 ≥2，才叫「能再练一次」**。

### 补的方法：每格换角度，不换皮

34 道全部与同格原题**考不同的东西**，按层分配角度：

| 层 | 这批补的角度 | 例子 |
| --- | --- | --- |
| L1 认得 | 给对应关系挑错、判断归属 | 三者「管什么/判据」的正确配对；哪一项不是 OPM 抓手 |
| L2 说得出 | 复述结构与边界 | 项目集五个绩效域；IT 治理四个目标；静态 vs 动态回收期 |
| L3 算得出 | 套规则处理一个情形 | 数据口径不一，成熟度下一步该做什么；穿行测试匹配 |
| L4 判得准 | 模糊场景做判断 | 「打包成项目集就能统一调度资源」「自己检查自己出具的报告」 |
| L5 迁得动 | 完整产出 | 三层管理结构设计、OPM 改进方案、价值交付链四环、平衡计分卡指标 |

### 三道特意设计的题

- **RK-S8-060（EMV + 沉没成本 + 临界概率）**：自建净 260 万 / 租用净 292 万 → 选租用；
  已花的 80 万可研费不计入；再算出「达预期概率高于约 68.4% 时自建才更优」。
  **最后这一问把静态结论变成了一条可重算的规则**——业务部门改口说概率能到 75%，
  结论就该翻回去，不会算这一步就答不出。
- **RK-S8-059（IRR 与 NPV 的取舍）**：甲 IRR 25% 但 NPV 只有 60 万，
  乙 IRR 18% 但 NPV 220 万，互斥时以 NPV 为准。专打「效率高＝更划算」这个直觉。
- **RK-S8-068（预测性维护）**：干扰项是「建可视化大屏」。
  这是项目里出现频率最高、又最容易被当成「数字化成果」的东西，
  但它只展示已发生的事实，不产生预测能力。
