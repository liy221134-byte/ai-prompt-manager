## 二、设计偏差（需要你确认）

1. 设计里写的是「导入依旧是先预览后确认」，实现做成了**选完文件直接按计划落库，然后用提示条报
   条数**（新增项目／资产／跳过）。理由是本轮时间有限，而这条路径**只新增不覆盖**、失败会回滚到
   无改动，风险可控。要不要补一个正式的预览步骤，由你决定。

## 三、界面补验进度

- [x] 提示词编辑器里建关系 → 保存 → 刷新后仍在。
      依据：目标下拉列出同项目提示词，保存后刷新，关系目标筛选里出现该目标并只筛出这条提示词。
- [x] 技术档案里勾选「偏离默认选型」不挂 ADR 时，保存被拦下并显示中文提示。
      依据：实测保存被拦，提示「「Supabase」偏离了默认选型，需要先选一条 ADR 说明原因。」，
      编辑器同时提示「当前项目还没有 ADR 文档」。
- [x] 标签与关系目标两个筛选下拉的组合结果符合预期。
      依据：实测全量 3 张卡片 → 按关系目标筛出 1 张 → 再叠加标签仍是 1 张。
      顺带修掉一个真 bug：默认项目里的提示词走的是老列表，不经过资产筛选，
      导致标签和关系目标这两个新筛选对提示词不生效；现在这两个条件对提示词也判一次。
- [ ] 关系目标归档后，详情里显示「目标已归档」。
      现状：代码里按目标状态标注，但还没在界面上走过一遍。
- [ ] 把 v2 备份导入一个空库时能真正建出项目和资产。
      现状：本轮尝试时页面先弹出了「发现本机旧数据」的合并提示，自动化上传没走到导入处理，
      需要单独一轮验证。另注：本地新建的库自带 3 条示例提示词，所谓「空库」并不是真的空。
