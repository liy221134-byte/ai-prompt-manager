## 一、这一版要解决的问题

M2 结束时页面能回答「6 块内容各层做了几题」和「还有 206 天」，但**不回答「我今天动哪块、做几道」**。
380 小时摊到 206 天是每天 1.8 小时，这个日程当时只活在 `docs/learning/v4-plan.md` 里，产品里没有。

M2 验收单第七节把「不做今日计划」列为下一版最该做的事，理由写在那一节：
「现在这页能告诉你缺在哪，仍不告诉你今天干什么」。

这一版就补它，同时把 M2 预留的两个字段（`weekly_hours` / `target_date`）做成可设置。

## 二、核心设计：不假装知道你今天学了几个小时

系统能观测到的只有答题记录：哪个模块哪一层做了几道、对了几道。
看书、看视频、抄笔记用了多久，它一概不知。

所以算的不是「已投入 3.2 小时」，而是**两条互相独立的位置**：

| 位置 | 怎么算 | 用来回答 |
| --- | --- | --- |
| 日历位置 | 按模块 `planned_hours` 占比，把起点到终点的总天数摊给各模块 | 按计划，今天该走到哪个模块 |
| 练习位置 | 第一个还有未做题（没做过，或做错过且没重做对）的模块 | 实际练到哪个模块 |

两者一对照就知道落后还是超前，不用编一个假工时。
日历落在 S3 而练习停在 S1 时，页面直说「按计划今天该在 S3，练习还停在 S1，先把手上这块收口」。

三个附带判断：

- **今日配额** = 该模块剩余题 ÷ 该模块剩余天数，向下取整后至少 1 道；
  上限 10 道。上限是必要的：落后时公式会算出几十道，人不该一晚上面对 40 道题。
- **今日选哪几道**：在该模块内从 L1 往上找第一个还有题的层，**错题排在新题前面**——
  已经错过的题信息量最大，重做一遍比多做一道新题值。
- **时间够不够**：已覆盖工时按模块练习覆盖比例折算（明确是估算），
  与「每周可投入小时 × 剩余周数」比。差 10% 以上缓冲才算够。

「没设终点」「没设每周投入」各自是独立状态，**不并进「时间够」**。
默认显示「判断不了」，不猜一个够。

## 四、这一版第一次给出的可执行结论

设置每周 10 小时后，中项主题的结论是：

> 时间紧：还需约 375 小时，只剩约 294 小时可投入，差 81 小时；
> 要赶上每周得投约 **13 小时**。

这是产品第一次给出「能拿去改什么东西」的数——不是「你要努力」，而是一个具体到小时的缺口，
和一个可以调的目标（每周投入，或考期）。

**按每周 10 小时，中项到 2027-05-22 是来不及的。** 这一点该在规划里被记住，
而不是等到 3 月报名时才发现。

## 五、自动验证

```
npm run typecheck                              → 无错
npm run test                                   → 690 tests / 0 fail（15 秒）
node --test tests/learning-daily-plan.test.mjs → 23/23（新增）
```

新增 23 项压在三处容易错的地方：

- **「完成」以最新一次作答为准**：做错过又做对，不该还挂在错题里；
- **配额必须有上限**：落后时公式算出几十道，界面会甩出 40 道题；
- **「没设终点」「没设每周投入」不能混进「时间够」**：状态是六种，不是一个布尔。

另外几项边界：模块没题时跳过（不占住「今天在哪个模块」）、
总天数为 0 或负数时不分天数、起点在未来时不出现第 0 天、
只要有一个模块没写 `planned_hours` 就整体退化成按模块数均分。

## 六、这一版刻意不做

- **不做错题本单独页面**：今日计划已经把错题排在前面，但「全部错题集中复」还需要一页。
  等错题真的攒起来再说——现在总共做了 1 道题。
- **不做各目标的今日计划汇总**：`/learning` 列表只显示主攻状态，不显示每个目标的今日配额。
  理由同上：同时只有一个主攻，其余目标的今日计划算了也没人执行。
- **不做学习时长记账**：没有 `learning_sessions` 表，也不打算造。
  上面说过，系统观测不到真实学习时长，硬记会变成「填表」，最后没人填。
- 不做诊断（M3）、自适应出题（M4）、AI 回填通路。

## 七、遗留与风险

| 项 | 说明 |
| --- | --- |
| 「已覆盖工时」是估算 | 按模块练习覆盖比例折算（做完该模块 1/3 的题就算覆盖 1/3 工时）。它只用来说明「来得及来不及时」，不是真实学习时长。真实学完一个模块花的时间跟做题数不成比例 |
| 当前只有 1 道答题记录 | 今日计划仍停留在「第 1 天 / 剩 117 道」。要看出它的价值，得连做几天 |
| 每周 10 小时不够这件事 | 结论已算出（差 81 小时）。要么把每周投入调到 13 小时，要么把考期往后挪——这是产品结论，不是产品能自动解决的事 |
| 中项主题包只有 118 题 | 380 小时学 118 道题，题量明显不足以覆盖全部知识点。缺的是内容，不是排程 |
| 内置浏览器截图走不通 | 仍超 10 MiB 限制、DOM 快照返回空。本轮验证走 Chrome CDP（带登录态、能执行 JS 读页面文本），比截图更可靠 |
