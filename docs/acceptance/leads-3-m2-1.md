# 线索 3 M2.1（发起采集的两条入口）验收清单

关联设计：`docs/leads-3-m2-design-and-tasks.md` 第十三节（M2.1 实现记录与偏离）
关联需求：`docs/leads-3-4-requirements-draft.md` 第一节「线索 3」的 M2；本版对应 US-4

## 验收标准

1. **两个入口在场**：`/external-sources` 顶部有「生成采集任务单」「给压缩包」两个按钮，
   与「新建采集」「运行采集合规检查」并列。
2. **生成话术**：点「生成采集任务单」→ 填目标来源（不填时生成按钮禁用）→ 点生成 → 出现话术；
   话术含**提炼要求、去重口径、合规硬约束、回填格式**四段，且含 `confidence: hypothesis`
   与「等我人工确认」两条硬要求。
3. **关注点与生态按需出现**：不填关注点时话术里不出现「重点关注」；不选生态时不出现「（生态：」；
   填了则都出现。
4. **一键复制**：点「复制话术」后按钮变「已复制」。
5. **不误读为联网**：弹层里明确写着「产品本身不联网搜索」。
6. **压缩包入口形态**：点「给压缩包」→ 弹层标题是「给压缩包（外部采集）」，
   且**不出现**「创建到哪个项目」，改为「这条来源是谁」（来源名 + 生态）。
7. **来源名必填**：外部采集模式下不填来源名点确认会被拦，提示「外部采集要填来源名…」。
8. **规则自动带假设级可信度与来源摘录**：经由该入口落库的规则，`confidence` 为 `hypothesis`、
   `sourceExcerpt` 为正文摘录（合规检查盯的两项）。
9. **自动生成采集记录**：同一批落库后，台账自动多出一条采集记录，落点指向这批新资产；
   刷新后仍在（不是前端假数据）。
10. **影响面收敛**：标准「导入文档包」入口（资产库页 → 导入文档包）行为不变——
    仍然要选项目、规则仍是 `draft` 且不带信任度、不生成采集记录。
11. **真在浏览器看到渲染**：两个弹层都在浏览器里真打开看过，不是只跑测试。
12. **全量检查**：`npm run check` 四道门全过——类型检查、测试、代码检查 0 error、生产构建；
   这道是线上部署的门（M1 曾因漏跑代码检查让线上部署连挂两次）。

## 已知限制

- **云端模式未在浏览器验证**：与 M2 同口径——本版写入范围仍是本机库，云端数据未推送；
  云端模式的浏览器实测留到 `npm run sync` 推送时一并做（并入 `docs/pending-items.md` 第 14 行）。
  **补充说明（2026-09-30 产品负责人反馈后补）**：本清单说的「本地已验」，验的是**独立验证库**
  （E 盘临时工作树的 `.data/prompts.sqlite`），**不是主库、也不是云端**。实际使用环境里主库 0 条
  采集记录、云端 0 条——所以「打开台账是空的」是**真的空**，不是渲染问题。原因与修复动作见
  `docs/pending-items.md`「2026-09-30 采集记录为什么是空的」。教训：写「已验」时必须说清验的是
  哪个库，验证库与用户库不是同一份文件时，这句话就不完整。
- **压缩包入口的 AI 提取需要配好 AI 服务**：未配 `AI_API_BASE_URL` / `AI_API_KEY` / `AI_MODEL`
  时，识别步骤会返回「AI 服务尚未配置」。本清单验证的是**落库这一段的模式差异**
  （信任度、来源摘录、自动生成采集记录），提取环节沿用既有链路未改动；
  本轮浏览器实测是拿一个本地模拟 AI 服务顶上去的（端口 3999，固定返回两条规则草稿）。
- **采集记录不设 `seq`**：自动生成的采集记录没有序号，排序时排在带序号的记录之后（按创建时间）。
  这是有意的——它是这一批的汇总记录，不占历史序号。
- **不做一键自动采集**：产品不联网、不自动入库、不自动升 active，与设计稿第三节「不做什么」一致。

### 过程中发现并修掉的问题

- **自己造的一个 bug**：外部采集模式下接口返回的 `projectId` 是 `null`。根因是路由里把
  「回退到公共库」只写进了传给 plan 的参数，算 `projectId` 时还在用解析出来的 `project`
  （外部采集时是 `null`）。修法：把回退结果提到一个 `effectiveProject` 变量，plan 与
  `projectId` 计算共用。接口用例「外部采集模式：不传项目也能落库…」正是这条的回归。
- **剪贴板 API 在无头浏览器不落地**：验证时复制按钮不变「已复制」，因为无头环境不是安全上下文。
  给组件加了 `document.execCommand("copy")` 兜底，并把 `navigator.clipboard.writeText` 打桩，
  验的是组件状态翻转（「复制话术」→「已复制」）这条真实逻辑，而不是浏览器是否真写了剪贴板。

### 环境处置（如实登记，避免下次重复踩）

- **dev 服务的 `.next` 缓存清理撞上批量删除守卫**：临时文件累计到 50 个后被拦
  （`SAFE_DELETE_BULK_CONFIRM_REQUIRED`），进程被终止。处置：只给这一个 dev 进程加
  `CODEBUDDY_SAFE_DELETE_ENABLED=0` 重启，它只删自己临时工作树里的构建缓存。
- **浏览器实测写的是验证库副本，不是主库**：E 盘临时工作树的 `.data/prompts.sqlite`
  （用 `PROMPT_DB_PATH` 指过去），截图与 `evidence-db.txt` 都取自它；本工作区主库保持干净交付状态。
  所以「台账 23→24」这类数字只在验证库里成立。
