# v1.0.0 整体验收清单

## 版本目标

发布个人 AI 提示词资产管理工具的第一个稳定版本，覆盖提示词采集、整理、检索、使用、
AI 合并、垃圾箱和 AI 优化，并补齐 v0.9.1 变量管理。

## 本期范围

### 包含

- 提示词新增、编辑、删除、搜索和 Markdown 预览。
- 变量识别、填写、实时预览和一键复制。
- AI 采集、AI 合并、垃圾箱恢复和 AI 优化。
- 变量逐条改名、降级为正文、选区设为变量和手动插入。
- 本地 SQLite、Supabase 云端、邮箱密码登录和账号数据隔离。
- JSON 备份导出与导入预览。

### 不包含

- 团队空间、评论和审核。
- 完整版本历史和版本差异选择。
- 提示词市场、浏览器插件和直接执行模型。
- 变量默认值、跨提示词统一变量名和自动润色。

## 人工验收

### 变量管理

- [ ] 通过 AI 采集生成含变量的草稿，进入编辑页后变量清单数量与正文一致。
- [ ] 在变量清单中改名，正文所有出现位置同步更新。
- [ ] 尝试改成已有变量名，页面显示明确错误且正文不变。
- [ ] 点击「降级为正文」，占位符消失，变量文字保留，清单同步移除。
- [ ] 在正文中选择一段文字并点击「选区设为变量」，正文出现对应占位符。
- [ ] 在变量输入框输入名称并点击「插入」，变量出现在当前光标位置。
- [ ] 插入已存在的变量名时提示会新增一处使用。
- [ ] 在详情抽屉点击「整理变量」，编辑抽屉打开且变量清单可操作。
- [ ] 点击取消后重新打开，已保存内容没有变化。

### 核心流程

- [ ] 找到提示词，填写变量，预览实时更新，复制的是替换后的最终文本。
- [ ] 没有任何变量时，详情页直接显示可用的复制按钮。
- [ ] 新增、编辑、删除、搜索和刷新后数据一致。
- [ ] AI 采集、AI 合并和 AI 优化都在确认后才写入数据。
- [ ] 垃圾箱可以恢复、永久删除和清空，合并与优化记录不互相串用。

### 云端与数据

- [ ] 邮箱密码登录、退出和刷新后会话状态符合预期。
- [ ] 云端账号 A 看不到账号 B 的提示词、垃圾箱和恢复记录。
- [ ] 导出备份后再导入，预览中的新增、更新、跳过结果正确。
- [ ] 已经在垃圾箱中的提示词不会被备份导入复活。

## 发布门禁

1. 执行迁移前先导出一次 JSON 备份。
2. `npm run check` 通过后，推送功能分支并等待 Preview 部署。
3. 在 Preview 完成变量管理人工验收。
4. 确认没有新增数据库迁移；如有新迁移，必须先应用并验证再合并。
5. 合并 `main` 并等待 Vercel Production 构建成功。
6. 在生产环境完成登录、变量管理、核心流程和备份检查。
7. 记录发布提交、Vercel 部署和回滚目标，然后打 `v1.0.0` 标签。

## 已知限制

- 界面只支持回到最近一次优化前，不支持选择更早的版本。
- 变量值不会持久化，只用于当前详情页的预览和复制。
- 降级变量后不会自动润色句子，需要用户在正文里自行调整。
- 个人工具不承诺高可用，生产数据恢复点取决于最近一次手动导出。
