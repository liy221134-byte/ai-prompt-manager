# 生产级项目指南地图

## 这份文档解决什么

它只回答四个问题，不解释怎么做：

1. 这个项目是什么规模和形态？
2. 现在处于哪个阶段？
3. 这个阶段必须读什么、必须产出什么、必须过哪道门禁？
4. 什么可以跳过？

流程细节在工程种子资产包里（`seed-packs/engineering-foundations/`），本文只做路由，
不重复内容。当前项目进度看 `docs/roadmap.md`。

## 第一步：给项目定性

### 规模（决定流程密度）

| 级别 | 判定信号 |
| --- | --- |
| 个人工具 | 只有自己或少量可信的人用；坏了能快速重建；数据不敏感 |
| 中型产品 | 有账号和数据库；有备份和发布要求；模块数量有限 |
| 大型平台 | 多模块、多团队、多系统集成；有可用性和性能指标 |
| 监管或高敏 | 涉及重要数据；内网或专网；有等保、审计、信创要求 |

判定步骤见 `assets/001-project-scale-classification.md` 的七步检查。

### 运行环境（决定部署和运维打法）

| 环境 | 判定信号 |
| --- | --- |
| 全托管 | 部署和数据库都用云服务，例如 Vercel + Supabase |
| 自建云主机 | 有服务器和公网，自己装、自己运维 |
| 公司托管 | 有内部平台和审批，只能提交不能直连 |
| 内网隔离 | 物理隔离或专网，进出要摆渡，远程基本用不上 |

### 阶段（决定这一次该做什么）

| 阶段 | 标志 |
| --- | --- |
| 0 立项 | 还没写代码，或只有想法 |
| 1 骨架 | 端到端能跑通一条最短链路 |
| 2 迭代 | 按版本加功能 |
| 3 加固 | 有真实用户，或者准备交付 |
| 4 发布与运维 | 上线之后的日常 |
| 5 交付与移交 | 交给客户运维接手 |

## 第二步：每个阶段的门禁

门禁必须可判定：说不清"拿什么证明过了"，这条门禁就是装饰。

| 阶段 | 必读资产 | 必产出 | 门禁 |
| --- | --- | --- | --- |
| 0 立项 | 001 规模分级、003 需求边界 | 一页纸：做什么、不做什么、验收标准、规模与环境标签 | 边界写清楚，规模和环境确认过 |
| 1 骨架 | 005 架构基线、006 端到端最小链路、008 接口与数据归属 | 能跑的最短链路、数据归属说明 | 端到端真的跑通，且留下证据 |
| 2 迭代 | 004 指标冲突、007 模块分解 | 每版一份《设计 + 任务清单》 | 一版只做一个子系统；测试先于实现；`npm run check` 通过 |
| 3 加固 | 009 质量画像、010 验收证据链 | 验收清单和证据 | 安全、备份、回滚、限额逐条有证据 |
| 4 发布运维 | 011 发布回滚、012 故障演练 | 发布操作单、回滚演练记录 | 在演练里真的回滚成功过一次 |
| 5 交付移交 | 011、本文的环境差异表 | 离线制品包、部署手册、回滚手册、诊断脚本、部署台账 | 客户运维照着手册独立部署一次 |

## 第三步：环境差异（同一条流程，四种打法）

| | 全托管 | 自建云主机 | 公司托管 | 内网隔离 |
| --- | --- | --- | --- | --- |
| 代码怎么进 | 推分支，平台自动构建 | 推分支，流水线拉取 | 提交工单或流水线 | 离线包摆渡 |
| 依赖怎么进 | 平台托管 | 公网或公司私服 | 公司私服 | 离线镜像包 |
| 迁移怎么执行 | 自动或手动调用函数 | 流水线执行 | 审批后执行 | 人工执行，备份先行 |
| 回滚怎么做 | 平台切换版本 | 镜像回滚加 SQL 回滚 | 走审批 | 软链接切回加 SQL 回滚 |
| 故障怎么响应 | 远程 | 远程 | 远程加工单 | 现场为主，争取 VPN |
| 谁有生产权限 | 我 | 我 | 平台或运维 | 客户运维，或我持账密 |

操作细节见 `docs/operations/` 下的迁移、发布回滚和备份文档。

## 第四步：可以跳过什么

按规模和阶段砍流程，不要一刀切：

- 个人工具：跳过发布门禁、跨账号验证、故障演练；保留需求边界、最小链路、验收证据。
- 不涉及数据结构变化：跳过迁移相关的全部动作。
- 纯界面和文案调整：按 `AGENTS.md`，不需要设计文档。
- 没有真实用户之前：跳过 SLA、值班、监控告警。

## 什么时候重新看这份地图

- 每次开新版本时复判一次规模、环境和阶段，成本是一行字。
- 规模升级时（个人工具变成有别人用）补跑对应阶段的门禁。
- 阶段跳跃时（例如直接要交付内网）回头补阶段 3 的门禁。

## 这份地图的边界

它防的是「一开始选错路线」，不替代阶段内的判断。
它不重复流程细节；一旦发现它在解释「怎么做」，那段内容应该挪回资产包。
