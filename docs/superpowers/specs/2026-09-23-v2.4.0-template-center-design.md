# 模板中心设计（v2.4.0）

## 文档状态

- 目标版本：`v2.4.0`，主题是「把模板变成资产，让编译产物能套自己的结构」。
- 状态：**待产品负责人确认**；按 2026-09-23「其余迭代该做就做」的授权，
  下面标了「按建议执行」的地方先按推荐做法推进，你有不同意见随时说，改动成本很低。
- 对应 [2.0 需求草案](../../v2-requirements-draft.md) 里的「文档模板」「模板中心」
  和 [2.0 资产管理底座计划](../../v2-plan.md) 里预留的 `template` 资产类型。
- 上游：`v2.3.0` 的规则编译已经能生成 `AGENTS.md`／`START_PROMPT.md` 草稿，
  这一版让它套模板。

## 一、做什么 / 不做什么

### 做什么

1. **开放模板资产类型**（`template`）：
   - 类型筛选新增「模板」；卡片、详情、编辑器都接上。
   - 模板元数据：产物文件名（生成时默认叫什么）、备注；变量不手填，
     从正文里的 `{{变量}}` 实时解析出来展示。
2. **导入模板**：工具栏「导入模板」可以一次选多个 Markdown 文件，
   每个文件直接建成一条模板资产（不走 AI，原文就是模板正文），
   文件名作为产物文件名。用它把仓库里的 `templates/new-project/` 模板库导进产品做验证。
3. **编译套模板**：编译面板里可以选一个模板：
   - 用模板正文作为产物结构；
   - 能自动填的变量直接填：`{{项目名称}}`、`{{一句话说明这个项目解决的问题}}`
     （取项目说明）、`{{技术栈}}`（取技术档案）；
   - `{{规则集}}` 是规则内容的插入点，替换成按层级和规则类型分组的规则段落；
   - 模板里没写 `{{规则集}}` 时，规则内容追加到产物末尾并注明；
   - 剩下没被填的变量原样保留，面板里列出「还要你填的变量」。
4. **模板库验证**：把 `templates/new-project/` 的 4 个文件导入产品，
   跑一遍套模板编译，核对元数据、来源、版本和变量替换结果。

### 不做什么

- 不做模板市场、共享、多人协作。
- 不做模板的自动生成（不拿 AI 从项目里反向生成模板）。
- 不做模板变量的类型校验（都是文本占位符，填不填由人决定）。
- 不做产物直接写外部文件，仍然是预览／复制／下载／存成文档资产。

## 二、数据和产品行为影响

### 新增内容

- 资产类型 `template` 从「预留」变成正式开放（本地和云端都不用改表结构，
  `asset_type` 是文本字段）。
- 模板元数据：`outputFileName`（产物文件名）、`note`（备注），都允许留空；
  关系沿用通用关系字段。
- 模板资产走现有编辑器形态：标题、说明、正文、状态、产物文件名和备注。

### 行为影响

- 编译面板多一个「模板」下拉：默认「内置结构」（就是现在的样子），
  选了模板就用模板正文当骨架。
- 生成的产物仍然是草稿，走原来的复制／下载／保存成文档资产。
- 变量替换只做「自动能确定的」几个，其它留给人工，替换结果在产物里看得见。

## 三、验收标准

1. 类型筛选能筛出模板；新建、编辑、查看模板都正常，产物文件名和备注能保存并读回。
2. 模板详情能看到正文里解析出来的变量清单。
3. 「导入模板」一次选多个 Markdown，能建出多条模板资产，产物文件名默认取原文件名。
4. 把 `templates/new-project/` 的 4 个文件导入后，资产列表里能看到 4 条模板，
   来源标记为导入、正文和文件一致。
5. 编译面板选中某个模板后，产物正文以模板为骨架，
   `{{项目名称}}`／`{{一句话说明…}}`／`{{技术栈}}` 被自动填上，
   `{{规则集}}` 替换成分组的规则段落；剩余未填变量在面板里列出来。
6. 模板里没有 `{{规则集}}` 时，规则段落追加到产物末尾并写明原因。
7. 产物仍能复制、下载、保存成文档资产；不修改模板本身、不写外部文件。
8. `npm run check` 通过（类型检查、自动化测试、lint、生产构建）。

## 五、需要你拍板的三个决定（先按建议执行）

1. **模板类型**：开放预留的 `template`（而不是塞进文档类型里用角色区分）。
2. **模板导入**：多选 Markdown 直接建模板资产，不做新的包格式；
   要一次装一整套模板时，多选即可。
3. **套模板的变量**：只自动填项目名、项目说明和技术栈三个，
   规则内容用 `{{规则集}}` 占位符；没写这个占位符就把规则追加到末尾。
   其余变量保留原样并列出待填清单。
