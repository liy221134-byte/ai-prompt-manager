# 设计文档唯一正本目录（本项目的，不是外部技能包）

## 这个目录是什么

放《设计 + 任务清单》的**唯一正本**。触发技术设计线时写一份到这里，确认后才动代码。
不开第二个规格目录，也不另起一套计划文档体系（规则见 `AGENTS.md`「设计门」）。

文件命名：`YYYY-MM-DD-<版本>-<主题>-design.md`。

## 名字的来由（读完这段就不会误判）

`superpowers` 这个名字来自**外部来源采集**——采集 S9（Exomem）那套由 MCP 解析出来的
规格系统产物。采进来之后，本项目把这个名字沿用成「设计文档目录」，**名字是借的，
内容全是本项目自己的**，与任何外部技能包无关。

保留这个名字的代价是容易被后续会话误判成「别家工具的目录」，改名的代价是
38 个文件引用了这个路径（绝大多数是 `docs/acceptance/` 下的历史验收记录，改了等于篡改
历史证据）。2026-09-30 的裁决：**不改名，用这份说明防误判**。

## 两条硬规矩

1. 历史验收记录里引用这个路径的地方**原样留着**，不要批量替换。
2. 这里只放「决定」，不写实现过程、完整 SQL 和成段代码。
