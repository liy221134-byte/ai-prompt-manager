# 云端题库交互优化 设计 + 任务清单（设计门）

日期：2026-09-29
输入：`docs/leads-4-cloud-practice-design.md`（线索 4 题库模块，T8–T12 已实施，已合并到 main 并上线；本次在此基础上做交互优化）
本次需求：
1. 把题库提升为与「公共资产 / 项目资产」平级的入口。
2. 练习首页增加「习题类型分类」与「习题状态分类」两个筛选维度。
3. 改造答题交互为左侧习题树 + 右侧答题区的经典布局，提交后给出明确对错与解析，并支持上一题/下一题任意切换（不再答完回列表）。
4. 补充 多选 / 判断 / 实操 样例题，让「习题类型」维度真正可筛。
状态：**已实施（代码完成，待合并到 main + 跑迁移 + 线上验证）**

> 口径纠正：用户口述为「线索 3 的云端题库」，经核对立项文档，云端题库实为**线索 4 的云端半边**。本设计按【线索 4 题库】口径。

## 一、做什么 / 不做什么

### 做什么

1. **入口平级**：把「练习题库」从公共视图「更多」菜单，提升为首屏与「公共资产 / 项目资产」并列的**第三个顶层切换项**（仅云端模式可见）。
2. **首页加两个筛选维度**：
   - **习题类型（题型）**：单选 / 多选 / 判断 / 实操。
   - **习题状态**：全部 / 未做 / 已做 / 错题——按当前账号在 `practice_attempts` 的作答记录实时计算。
3. **两栏经典布局（答题页）**：改为左侧习题树（按分类分组、带状态色点、点击任意跳转）+ 右侧答题区（题干/选项/提交/对错反馈与解析/上一题·下一题）。答完不再强制回列表，可在树中任意切题。
4. **对错反馈与状态可见**：提交后立即显示「回答正确/错误」、正确答案（多选列出正确项）、解析；题目树与列表的色点反映本人作答状态。
5. **补充样例题型**：往题库加 多选 / 判断 / 实操 样例题（随 `type` 迁移一并写入），让「习题类型」筛选真正有多档可选。
6. **保留现有「分类（话题）」分组**，作为筛选命中的题目列表/习题树的子结构。
7. **保留现有功能**：全部随机练习、错题重练、练习本类、单题。

### 不做什么

- 不引入本地模式题库（保持云端专属，沿用现有约定）。
- 不做题型 / 状态的「增删改」管理后台（题库内容由种子与管理通道写入，沿用 leads-4 约定）。
- 不改变答题与记录逻辑（`practice_attempts` 表结构不变；`practice_questions` 除新增 `type` 字段外不变）。
- 不做实操题与题库的联动回传（沿用 leads-4 第十节：M0 解耦）。

## 二、数据和产品行为影响

- 新增 `practice_questions.type text` 字段（一次 Supabase 迁移；现有种子题因默认值自动归「单选」；RLS 不变，仍全局可读）。
- 随 `type` 迁移追加 8 道样例题（多选 3 / 判断 3 / 实操 2），分布到现有分类（工程化与质量保障、Web 与接口基础、AI 编码基础、版本控制与协作、AI 安全与伦理、数据库基础、终端与运行、前端基础）。实操题 `options` 为空数组，由答题页展示任务与参考要点。
- `practice_attempts` 不新增字段；状态由前端按 `user_id` 拉取本人记录后在内存计算（未做/已做/错题）。
- 入口变化：`prompt-library` 首屏从「两视图」变为「两个资产视图 + 一个练习入口」，仅云端模式出现练习入口。
- 行为不变：未登录访问 `/practice` 仍走现有登录门（`redirect('/login')`）。

## 三、验收标准（每条可判定）

1. 云端模式下，首屏出现与「公共资产 / 项目资产」并列的「练习题库」入口；本机模式下该入口不出现。
2. 练习首页顶部有「习题类型」与「习题状态」两组筛选，切换后题目列表实时过滤；题型与状态筛选可叠加。
3. 状态「错题」仅显示本人答错过的题；「未做」仅显示本人无作答记录的题；「已做」显示有作答记录的题。
4. 题型筛选出现 单选 / 多选 / 判断 / 实操 多个选项；选择各档能筛出对应样例题。
5. 答题页为左树 + 右答题两栏：左侧树按分类分组、带状态色点、点击可跳到任意题；右侧显示题干/选项、提交后展示对错与解析、支持上一题/下一题。
6. 提交后明确显示对错（正确绿、错误红）并给出解析；错题在树与列表中标记红色。
7. 现有功能（随机练习 / 错题重练 / 练习本类 / 单题）在加筛选后仍然可用；随机练习遵循当前筛选（无筛选则为全量）。
8. `npm run check:fast` 通过（类型检查 + 自动化测试无报错）。
