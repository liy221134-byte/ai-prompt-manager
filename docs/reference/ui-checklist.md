# 界面检查清单（8 类，按影响排序）

> 用途：做界面或改界面时，按这份清单从「影响最大」往下过一遍。
> 来源：Claude Skills 的 `ui-ux-pro-max` 技能的速查部分（外部来源采集第六批的核对结果），
> 以及 `frontend-design` 技能里的「生成味」清单。
> 定位：这是**参考清单**，不是规则——清单会随实践变；真正的硬约束在
> `RULE-DESIGN-QA-001`、`RULE-DESIGN-TEMPLATE-LOOK-001`、`RULE-DESIGN-COPY-001` 里。

## 1. 无障碍（最要紧）

- 正文对比度至少 4.5:1
- 可交互元素有可见的焦点样式
- 有意义的图片写描述性替代文字
- 只有图标的按钮加无障碍名称
- Tab 顺序和视觉顺序一致
- 表单用 `label` 关联控件

## 2. 触控与交互

- 触控目标至少 44×44 像素
- 主要交互用点击／轻触，不依赖悬停
- 异步操作期间按钮禁用，避免重复提交
- 错误提示靠近出问题的地方
- 可点的元素给出手型光标

## 3. 性能

- 图片用 WebP、按需尺寸、懒加载
- 尊重「减少动效」的系统设置
- 异步内容预留位置，避免跳版

## 4. 布局与响应式

- 视口声明 `width=device-width, initial-scale=1`
- 移动端正文至少 16px
- 内容不撑出横向滚动
- 层级用固定的一套 z-index 刻度（10 / 20 / 30 / 50）

## 5. 排版与配色

- 正文行高 1.5～1.75
- 行宽 65～75 字符
- 标题字体与正文字体气质匹配

## 6. 动效

- 微交互 150～300 毫秒
- 动的是 transform 和 opacity，不动宽高
- 有加载状态（骨架屏或转圈）

## 7. 风格选择

- 风格和产品类型匹配
- 所有页面用同一套风格
- 图标用 SVG，不用 emoji

## 8. 图表与数据

- 图表类型匹配数据类型
- 配色无障碍
- 复杂图表给一张可读的表格作为替代

## 附：避开「生成味」的默认样式

这几类不是不能用，而是**默认就会产出、所以要先怀疑**：

1. 暖奶油底 + 高对比衬线 + 陶土色点缀；
2. 近黑底 + 单一荧光点缀；
3. 大报风：细线分隔、零圆角、密集分栏；
4. SaaS 卡片套件：一层级一个圆角、每张卡同一个柔和灰阴影、渐变当装饰；
5. 模板外壳：每个标题上方一行全大写小标签、元信息用中点连接、「单词 — 碎片」破折号、
   用 #0B0B0B 冒充黑、小数据用等宽字体、链接和按钮后面加 →。

排版的三个常见痕迹：只把标题里一个词加粗或变色、标签全大写、内容上方加多余的小标签。
详细做法见 `RULE-DESIGN-TEMPLATE-LOOK-001` 和 `templates/methods/design-plan.md`。
