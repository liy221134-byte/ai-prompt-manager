## 二、现在能做什么

**三条链路，各自独立**：

1. **提示词**（公共资产库）：找到 → 填变量 → 一键复制；采集、优化、合并都先预览再保存。
2. **项目文档**（文档视图）：需求 → 规格与计划 → 交付 → 验收 → 发布，六段分组，缺哪环看得出来。
3. **代码**（代码视图）：从建表语句或代码目录导入模块／数据／接口／测试节点，做两层影响分析。

**支撑能力**：规则编译成 AGENTS.md；工程基线按质量等级查缺；立项起步包（推荐 + 四条立项提示词 +
开发体系包）；沉淀回流（提升为公共资产、上游提醒、沉淀体检）；发布门禁与回滚目标；
本机 MCP（AI 直连读写，能力不超过界面）。
