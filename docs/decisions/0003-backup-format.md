# 备份格式决策

## 决策

使用带类型和版本号的 JSON 文件作为提示词备份格式。

示例结构：

```json
{
  "type": "ai-prompt-manager-backup",
  "version": 1,
  "exportedAt": "2026-09-17T08:00:00.000Z",
  "prompts": []
}
```

## 原因

- JSON 可以被浏览器直接读取和写入。
- 文本格式方便检查、迁移和版本管理。
- 类型字段可以识别备份文件是否属于本产品。
- 版本字段支持未来升级数据格式。
- 导出时间用于展示备份时间和辅助冲突判断。

## 导入规则

1. 导入前必须校验类型、版本、导出时间和全部提示词字段。
2. 备份文件内出现重复提示词标识时拒绝导入。
3. 本机不存在的提示词执行新增。
4. 备份版本更新时间较新时执行更新。
5. 内容相同、备份版本较旧或时间相同时执行跳过。
6. 导入过程不删除本机已有提示词。
7. 文件校验失败时不修改任何本机数据。

## 当前限制

- 备份文件最大支持 5 MB。
- 导入没有部分写入功能，用户确认后一次性合并。
- 本地备份不会自动上传到云端。
- 当前冲突规则只比较更新时间，不提供逐字段人工合并。
