# 本地存储决策

## 决策

第 2 周使用浏览器 `localStorage` 保存个人提示词，存储键为 `ai-prompt-manager:prompts`，并带独立的版本号。

## 原因

- 当前产品明确为个人使用，不需要多设备同步。
- 不引入账号、数据库或外部服务，可以优先验证核心使用流程。
- 数据操作集中在独立存储模块中，后续接数据库时可以替换数据源。
- 保留版本号，方便以后迁移数据结构。

## 已知限制

- 数据只在当前浏览器中可用。
- 清除浏览器网站数据会删除提示词。
- 无法跨设备访问或多人协作。
- 暂不保存历史版本，删除操作不能直接恢复。

## 后续处理

当确认需要多设备访问、数据备份或多人协作时，再接入数据库，并完成以下迁移：

1. 保留现有本地数据结构。
2. 为提示词增加用户归属和数据库标识。
3. 提供本地数据向数据库导入的迁移流程。
4. 数据迁移成功后仍保留一个版本周期的本地备份。
