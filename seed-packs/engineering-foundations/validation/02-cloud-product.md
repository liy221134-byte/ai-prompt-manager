# 中型云端产品编译验证

## 验证对象

使用中型云端产品画像编译一套可生产使用的开发体系。

## 输入约束

- 包含登录和云数据库。
- 有真实用户数据或长期积累内容。
- 小团队维护。
- 需要跨设备、备份、发布和回滚。

## 期望输出

```text
数据与安全边界
-> 架构基线
-> 登录和数据最小链路
-> 工程门禁
-> 备份和回滚
-> 纵向功能迭代
```

## 必须包含

- 账号隔离。
- 密钥和环境范围。
- 数据备份和恢复。
- 工程检查与发布门禁。
- 验收证据链。

## 必须避免

- 自动降级到不安全配置。
- 只验证代码，不验证数据和回滚。
- 把 Preview 与 Production 密钥混用。
