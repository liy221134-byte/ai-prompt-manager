# 大型平台编译验证

## 验证对象

使用大型平台画像编译一套多团队、多模块实施体系。

## 输入约束

- 多个核心分系统和公共支撑能力。
- 多团队并行开发。
- 外部系统和历史系统接口较多。
- 强性能、可靠性、安全和合规要求。

## 期望输出

```text
项目复杂性分级
-> 需求与指标基线
-> 领域和数据所有权
-> 架构与公共平台
-> 两条端到端最小链路
-> 服务域并行交付
-> 集成、专项测试和试运行
```

## 必须包含

- 指标冲突检查。
- 模块和团队映射。
- 接口契约和数据所有权。
- 非功能与安全门禁。
- 分阶段验收和故障恢复。

## 必须避免

- 全部前端完成后才设计后端。
- 全部模块使用一个无边界后端。
- 模块完全独立，重复建设公共能力。
- 依赖未验证的国产化、可信计算或 GPU 环境。
