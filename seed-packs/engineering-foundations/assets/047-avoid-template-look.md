# 别做出模板味的默认样式

## 核心结论

「风格新潮」不是形容词，是一条能执行的纪律：**先把设计计划拿出来，问「哪一部分是我对任何同类页面都会产出的默认？」，是默认就改掉，并说明改了什么。**

四步：

1. **从主题取材**：独特来自主题本身——玩具的审美和金融仪表盘完全不同。行业、材料、场景里的话，才是视觉选择的来源。
2. **避开已知的生成味**——它们是「默认」而不是「选择」：
   - 暖奶油底 + 高对比衬线 + 陶土色点缀；
   - 近黑底 + 单一荧光点缀；
   - 大报风：细线分隔、零圆角、密集分栏；
   - **SaaS 卡片套件**：一层级一个圆角、每张卡同一个柔和灰阴影、渐变当装饰；
   - **模板外壳**：每个标题上方一行全大写小标签、元信息用中点连接、「单词 — 碎片」式破折号、用 #0B0B0B 冒充黑、小数据上等宽字体、链接和按钮后面加 →。
   排版还有三个常见痕迹：只把标题里的一个词加粗或变色、标签全大写、内容上方加多余的小标签。
3. **对照简报复查**：先出一版设计计划（4～6 个命名色值、字体与角色、布局概念加 ASCII 线框、原则），再拿它对着简报问「哪一块换成别的主题也成立」——改掉，并说明改了什么、为什么。
4. **胆量花在一处**：留一个记忆点，周围保持安静。结构件（编号、边框、分隔线、标签）要承载信息，不承载信息就是装饰，删掉。

两条补充：编号只用在真的是序列的地方；动效只在「回答人的动作、让人看清什么变了」或一次有编排的亮相时用——每屏淡入上移、每张卡都有 hover，是默认不是设计。

## 使用条件

- 定稿档：首次确定产品整体视觉风格时。
- 有「要新潮」这类要求、需要避免撞脸通用模板时。

## 不适用场景

- 简报已经指定了视觉方向：按简报做，**简报自己的话永远优先**，包括它点名要上面某一种风格。
- 配置档：界面锁在固定底座里（Vben／若依这类），做的是主题与布局配置，不重画底座已有的东西。
- 改文案、调间距、换图标这类局部调整。

## 判断步骤

1. 先确认简报说的是什么产品、给谁用。
2. 出一版设计计划：色值 / 字体与角色 / 布局概念（加 ASCII 线框）/ 原则。
3. 自查一遍：「哪一部分是我对任何同类页面都会产出的默认？」。
4. 改掉它，并记下「改了什么、为什么」。
5. 选一处当记忆点，其余保持安静、克制。
6. 做完对着截图自评一遍。

## 失败模式

- 直接套通用卡片网格 + 柔和阴影 + 渐变装饰，换掉文字就能给别人用。
- 每个标题上面都加一行全大写小标签、元信息用中点串起来——换主题也不变。
- 到处都是「装饰」，却没有一个能被记住的点。
- 把 01 / 02 / 03 编号用在不构成序列的内容上。
- 抄别人稿子的外观，而不是从这份简报的主题取材。

## 验证证据

- 那份设计计划（色值、字体与角色、布局概念、原则）。
- 复查时写下的「改了什么、为什么」。
- 成品里能指出唯一那个记忆点。
