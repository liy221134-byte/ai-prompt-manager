# 个人工具

## 典型特征

- 单人使用或少量可信用户。
- 数据和流程相对简单。
- 故障影响有限，可快速重建。
- 不需要团队权限、复杂审批和正式合规审计。
- 预算和运维成本敏感。

## 推荐路线

```text
核心用户流程
-> 静态或交互原型
-> 本地可用闭环
-> 按需增加数据库、登录和部署
```

## 必选资产

- 项目规模与复杂度分级。
- 需求边界与外部依赖澄清。
- 端到端最小链路。
- 验收证据链。

## 可选资产

- 发布、回滚与恢复。
- 生产故障演练。

## 不应强制

- 多团队治理。
- 复杂微服务。
- 全套等保和可信计算。
- 多环境和大规模性能测试。

## 验收重点

- 核心流程可用。
- 数据可以导出和恢复。
- 页面在目标设备正常工作。
- 不泄露密钥和个人数据。
