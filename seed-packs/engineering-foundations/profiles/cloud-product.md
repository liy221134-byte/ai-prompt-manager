# 中型云端产品

## 典型特征

- 个人或小团队维护。
- 包含登录、云数据库、多设备同步或外部 AI 服务。
- 用户数据不能丢失，错误会影响真实使用。
- 需要版本、备份、回滚、监控和成本控制。
- 可能逐步扩展到更多模块。

## 推荐路线

```text
范围与数据边界
-> 架构和工程基线
-> 登录、数据和部署最小链路
-> 功能纵向迭代
-> 生产加固与恢复演练
```

## 必选资产

- 项目规模与复杂度分级。
- 需求边界与外部依赖澄清。
- 架构与工程基线。
- 端到端最小链路。
- 项目质量画像与必选门禁。
- 验收证据链。
- 发布、回滚与恢复。

## 可选资产

- 按业务能力拆分模块。
- 接口契约与数据所有权规则。
- 生产故障演练。

## 验收重点

- 登录和数据隔离。
- 数据备份与恢复。
- 环境变量和密钥范围。
- 构建、测试、部署和回滚。
- 免费额度、成本和服务暂停风险。
